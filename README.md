# SemantIAr · PNL clínico: del texto libre a la recuperación de conceptos clínicos

Explorador interactivo de representaciones vectoriales, recuperación de conceptos SNOMED CT y anotación humana en español rioplatense.

Sitio web disponible en: **[https://manwithbarba.github.io/semantiar-espacio-semantico/](https://manwithbarba.github.io/semantiar-espacio-semantico/)**

---

## Propósito

Este recurso forma parte del proyecto de investigación doctoral **SemantIAr** (Facultad de Ciencias Médicas, Universidad Nacional de La Plata). Funciona como un dispositivo de formación y divulgación académica para comprender cómo una expresión clínica extraída de un texto libre se representa mediante modelos densos de PNL (SapBERT + FAISS) y se compara con la referencia anotada por profesionales de la salud.

## Procedencia de los datos

- El explorador analiza registros del [corpus publicado de SemantIAr, release v1.0.0-rc1](https://github.com/manwithbarba/semantiar-terminology-corpus/releases/tag/v1.0.0-rc1).
- La terminología utilizada corresponde a la edición de **SNOMED CT congelada al 20-05-2026**.
- **Privacidad y desidentificación**: Este repositorio y la aplicación web contienen únicamente datos públicos agregados. **No se publican textos originales de notas clínicas**, números de historia clínica, identificadores de pacientes ni identificadores de personas anotadoras.
